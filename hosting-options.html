Fast Good — Hosting Options

Reference doc for hosting the app and switching providers. Data always lives in your browser's localStorage — independent of where the app is hosted.

Key Facts

Your fasting data (history, active fast, settings) is stored in localStorage in your browser. No server ever sees it.
The service worker caches all app files after the first load. Once cached, the app works completely offline.
Switching hosting providers has zero effect on your data. You can move anytime.

Option 1 — GitHub Pages

Current   Easiest

GitHub hosts your static files for free over HTTPS. Your fasting data never touches GitHub — only the app code (HTML, CSS, JS) is public.

Setup Steps

  1. Create a new GitHub repo (e.g. fast-good). Can be public or private.
  2. Push the contents of projects/fasting-app/ to the repo root: 
    cd C:\Users\Will\magi\projects\fasting-app
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/fast-good.git
git push -u origin main
  3. In the repo on GitHub: Settings → Pages → Branch: main → Save.
  4. Your app is live at https://YOUR_USERNAME.github.io/fast-good/ within ~60 seconds.
  5. Open that URL on your phone, then use Share → Add to Home Screen (iOS) or the install prompt (Android) to install the PWA.

Updating the App

After any code change, commit and push. GitHub Pages redeploys automatically. Bump the cache version in sw.js (fast-v11 → fast-v12, etc.) and hard-refresh on each device to pull the new version.

Switching Away Later

Just stop using the GitHub Pages URL. Export your data from Settings → Export JSON, then import it on the new host. Or just let localStorage persist if you're using the same browser.

Option 2 — Tailscale

Most Private

Tailscale creates a mesh VPN between your devices. Your phone can reach your home PC (or a home lab server) from anywhere as if it's on the same LAN. No port forwarding, no public exposure.

Setup Steps

  1. Install Tailscale on your PC: tailscale.com/download
  2. Install Tailscale on your phone (iOS App Store / Google Play).
  3. Sign in to the same Tailscale account on both devices.
  4. Serve the app from your PC or home lab server: 
    cd C:\Users\Will\magi\projects\fasting-app
python -m http.server 8080
  5. On your phone (with Tailscale active), open http://YOUR_PC_TAILSCALE_IP:8080. Find the IP in the Tailscale admin console or app.
  6. Install as PWA from that URL. Once cached, it works offline even when Tailscale is off.

Home Lab Upgrade Path

Move the file server from your PC to a home lab machine that stays on 24/7 (e.g. a Proxmox VM or LXC container running nginx). This means the app is always reachable regardless of whether your PC is on. A good Ansible playbook target.

Note on HTTPS

Tailscale provides HTTPS via its MagicDNS + HTTPS certificates feature. Enable it in the Tailscale admin console under DNS settings, then use https://your-machine-name.tail....ts.net:8080 (or configure nginx to terminate TLS). Required for the PWA install prompt on Android Chrome.

Option 3 — Cloudflare Tunnel

Home Lab

Cloudflare Tunnel exposes a local service to the internet via an encrypted outbound tunnel — no port forwarding, no public IP needed. You get a real HTTPS URL. Free tier is sufficient.

Setup Steps

  1. Create a free Cloudflare account and add a domain (or use a free *.trycloudflare.com URL for testing).
  2. Install cloudflared on your home lab server.
  3. Authenticate: 
    cloudflared tunnel login
  4. Create a tunnel: 
    cloudflared tunnel create fast-good
  5. Configure it to point at your local file server (e.g. http://localhost:8080) and run it.
  6. Your app is available at https://fast-good.yourdomain.com from anywhere.

When to Use This Over Tailscale

Tailscale is simpler for personal use. Cloudflare Tunnel makes more sense if you want to share the app URL with someone else, or if you're already running Cloudflare for other home lab services.
